## 1. 记账类软件

### 1.1 随手记（国内老牌，功能最全）

**核心功能**
- 多账本：30+ 模板（学生生活费、班费、差旅报销、合租、恋爱、装修、宠物、奶茶店、人情账、宝宝账……）
- 多人协同记账 + 角色权限（员工记账老板看）
- AI 语音记账、图片识别批量记账（小票/支付截图自动识别）
- 自定义记账键盘
- 18 种报表（饼图 + 条形图，可触摸交互）
- 流水日历（每日收支一目了然，支持跨天补账）
- 多账户管理（资产 / 负债 / 净资产，可下钻往来明细）
- 预算、借贷中心、票据识别
- 云端多端同步、误删恢复、操作留痕
- 桌面小组件、微信小程序、网页端

**特色**
- 账本模板体系全市场最全
- 多人协同 + 权限细分
- 图片识别批量记账（一次导入多笔）

**被广泛吐槽的点**
- 太重：普通用户只想记午饭，却被账本模板/会员中心/理财入口劝退
- 心理负担大：会纠结"要不要先建账本""分类要不要整理"

---

### 1.2 MoneyWiz（国外专业级，功能天花板）

**核心功能**
- 银行直连：40,000+ 银行 / 55 国，AI 自动分类、自动识别转账与退款、自动对账
- 手动账户 + 导入 OFX / QIF / CSV / MT940
- **投资追踪**：股票、期权、债券、加密、外汇、pre-IPO/pre-ICO
- 预算（含信封预算法）+ 目标，支持分组、实时进度、预算间调拨
- 账单与订阅管理 + **现金流预测**（点日历任意日期 → 即时预测未来余额）
- 30+ 报表（可保存、分组、导出 PDF/CSV）
- 多币种 + 自动汇率刷新
- 256 位端到端加密
- 全平台（iPhone / iPad / Mac / Apple Watch）
- 账户分组、批量编辑、银行对账、自定义账户图标、归档旧账户

**特色**
- 银行直连 + AI 学习分类（越用越准）
- **现金流预测**——这是它最被称道的能力
- 个人记账 App 里投资追踪最强
- 周更 + 公开 roadmap

---

### 1.3 YNAB（方法论驱动，非纯工具）

**核心：零基预算四法则**
1. **给每一块钱安排工作**——收入进来就分配到具体分类，直到余额为零
2. **拥抱真实支出**——把年缴保险、旅行、车险等不规则支出摊到每月（沉没基金）
3. **随需调整**——超支不内疚，从别的分类调钱过来，预算是活的
4. **让钱变老**——目标是花"至少 30 天前赚的钱"，脱离月光

**其他功能**
- 银行同步（12,000+ 机构 via Plaid，只读）
- 目标追踪（储蓄目标 / 债务还清 / 月度资金 / 每周贡献）
- 报表：分类支出、净资产趋势、收支对比、**Age of Money 指标**
- 家庭共享：一份订阅最多 6 人共用一本预算
- 教育体系：免费工作坊、播客、博客、25 万人的 r/ynab 社区

**特色**
- 卖的是**方法论**而非功能，用户黏性极高（平均首年省 $6,000）
- Age of Money 量化"你是否脱离月光"
- 不规则收入的自由职业者适配最好

**不足**
- 贵（$14.99/月，或 $109/年）
- 学习曲线陡（前 2–4 周痛苦）
- 无投资追踪、无税务功能
- 需要主动参与，不适合"装了就不管"的用户

---

### 1.4 钱迹（国内极简派代表）

**核心功能**
- 无广告、无开屏、无理财（核心卖点）
- **3 步完成记账**（打开 → 选分类 → 输金额）
- 丰富的多维度统计报表
- 资产管理（记账后同步更新账户余额）
- **导入能力极强**——几乎支持所有主流记账软件的数据导入
- 夜间模式 + 多配色
- 全平台（iOS / Android / Mac / Windows）
- 多币种、本地备份

**特色**
- 极简纯粹，只做记账
- **数据迁移友好**——换软件时历史记录不丢，这是它最大差异化
- 免费且无广告

---

### 1.5 挖财记账

- 数据可视化强：自动生成清晰图表，分类占比一眼可见
- 场景模板：家庭装修、亲子育儿、自驾出行等专项账本
- 小票扫描识别自动录入
- 分类统计支持**同比环比**
- 完整月度消费报告
- 数据导出方便

---

### 1.6 Timi 时光记账（治愈系手账风）

- 手账风格 UI，记账像写日记
- **心情标签**：每笔支出可打心情标签
- 每笔支出可配照片（喝咖啡拍照存进去，翻账本像看生活记录）
- 自定义贴纸
- 彩色饼图 / 折线图
- 月度花销提醒（接近预设额度自动提醒）

---

### 1.7 叨叨记账 / 松鼠记账（游戏化派）

- **虚拟角色互动**：记一笔买奶茶，角色跳出来说"今天喝奶茶啦，少糖更健康哦"
- 记账变成"和朋友聊天"，降低心理负担
- 连续记账打卡得勋章
- 趣味攒钱：每记一笔支出，往虚拟松鼠窝存一笔攒钱金
- 分类图标可爱

**洞察**：这类产品解决的不是"记不记得"，而是"能不能坚持"。

---

### 1.8 鲨鱼记账（极速派）

- **3 秒记账**：打开 APP 直接进入记账页
- **免注册**，下载即用
- 大字体大按钮（适老化，给爸妈装）
- 定时记账提醒

## 2. 任务 / 笔记类软件

### 2.1 滴答清单（TickTick，国内最受欢迎）

**核心功能**
- **日历视图**：年 / 月 / 周 / 日 / 议程 / 多日 / 多周，共 7 种
- **番茄钟**：25 分钟专注
- **习惯打卡**：习惯库 + 灵活追踪 + 统计
- **倒计时**：生日、纪念日、考试、项目截止
- 多种视图：看板、时间线、分屏、**艾森豪威尔矩阵（四象限）**、便签
- **AI 语音捕获**：说话即建任务，自动提取日期/优先级/批量创建
- **AI 音频摘要**：会议录音 → 转录 + 结构化摘要
- **自然语言识别**：输入时自动识别"下周三下午 3 点"
- **过滤器**：自定义如"本周高优先级任务"
- 键盘快捷键 + 命令菜单
- 协作：共享清单、分配任务
- 集成：订阅日历、Notion、**MCP / CLI 自动化**
- 统计：任务完成、专注时长、习惯日志
- 40+ 主题
- 微信提醒、**持续提醒**（不完成一直响）

**特色**
- 任务 + 日历 + 番茄钟 + 习惯 **四合一**
- AI 语音捕获 + 音频摘要（2026 年重点发力）
- MCP 自动化工作流（可接外部系统）
- 艾森豪威尔矩阵

---

### 2.2 Things 3（设计天花板，GTD 最佳实践）

**核心功能**
- **GTD 原生结构**：Inbox / Today / Upcoming / Anytime / Someday + Areas + Projects
- Apple Design Award 获奖设计，交互与动效极佳
- **自然语言日期解析**（业界最快最准）
- Mac 键盘快捷键（重度用户效率极高）
- 标题分组（Headings）、标签、快速录入
- 本地优先 + 可选同步
- **一次性买断**（iPhone $9.99 + Mac $49.99，无订阅）
- Apple Watch / iPad / Mac 全原生

**不足**
- 仅 Apple 生态，无 Windows / Android / Web
- 无协作
- 无日历视图（靠 Upcoming 列表）

---

### 2.3 Todoist（跨平台 + 协作 + 游戏化）

**核心功能**
- 全平台（iOS / Android / Windows / Mac / Web / Linux）
- 自然语言输入优秀
- **Karma 积分系统**：连续完成任务累积 Karma、等级、连续记录
- **生产力图表 / 趋势图**
- 过滤器、标签、优先级
- 协作：共享项目、任务分配、评论
- **80+ 原生集成 + Zapier**
- 日历视图（Premium）
- 行业领先的 widgets

**特色**
- **Karma 游戏化** + 生产力趋势可视化
- 协作能力强
- 集成生态最广

---

### 2.4 Notion（模块化工作台）

- 数据库 / 看板 / 页面嵌套，自由度极高
- 双链
- 模板生态
- 协作 + 分享
- Notion AI

**不足**：上手陡（容易"光搭不用"）、打开慢、数据仅云端、离线弱

---

### 2.5 Obsidian（本地优先 + 双链）

- 本地 Markdown 文件，数据 100% 自有
- **双向链接 + 知识图谱**（核心差异化）
- 插件生态极丰富
- 强搜索 + 标签筛选
- 个人完全免费，可离线

**不足**：学习门槛较高，移动端体验弱于桌面

---

### 2.6 flomo（极简碎片记录）

- 极简快速记录碎片想法，零压力
- 标签为主（#标签 组织）
- **每日回顾**：自动推送旧笔记，促进复盘（核心特色）
- 微信直接输入
- 热力图（记录习惯可视化）

**洞察**：flomo 的"每日回顾"是**最低成本的复盘机制**——不需要你主动写复盘，系统把旧笔记推给你。

## 4. 差距分析

### 4.1 功能维度

| 能力 | 主流覆盖度 | Personal Life OS | 差距等级 | 说明 |
|---|---|---|---|---|
| **全局搜索** | 14/14 | ❌ | **高** | 唯一全行业都有而我们没有的能力 |
| **数据导出** | 14/14 | ❌ | **高** | "数据自有"的最后一块拼图，缺它则自有性不完整 |
| **数据导入** | 8/14（钱迹最强） | ❌ | **高** | 决定用户能否从别的软件迁过来 |
| **标签系统** | 9/14 | ❌ | **高** | 分类是树形单选，标签是多维度多选，灵活性差一个量级 |
| **账户 / 多账本** | 记账类 6/8 | ❌ | **高** | 无法区分现金/银行卡/支付宝，无法记转账 |
| **日历视图** | 任务类 4/6、记账类 3/8 | ❌ | **高** | 时间维度的数据呈现缺失 |
| **快速记账入口** | 记账类 8/8 | ❌ | **高** | 竞品普遍 3 秒/3 步，我们需导航到表单页 |
| **投资 / 资产追踪** | 4/14 | ❌ | 中 | MoneyWiz、挖财有 |
| **批量操作** | 10/14 | ❌ | 中 | 批量改分类、批量删除 |
| **图片识别记账** | 4/8 | ❌ | 中 | 已有 AI 基础设施，接入成本相对低 |
| **游戏化激励** | 5/14 | ❌ | 中 | 叨叨/松鼠/Todoist Karma；我们仅打卡有连续天数 |
| **四象限 / 看板视图** | 3/6 | 部分 | 中 | 任务有状态，但无优先级×紧急度矩阵 |
| **多人协同** | 5/14 | ❌ | 中 | 架构改动较大 |
| **快捷键体系** | 8/14 | 弱 | 中 | 仅 Escape/Enter，无全局快捷键 |
| **银行自动同步** | 3/14 | ❌ | 低 | 自托管难做、合规风险高，**不建议做** |
| **番茄钟** | 2/6 | ❌ | 低 | 非核心 |
| **桌面小组件** | 4/14 | ❌ | 低 | PWA 场景价值有限 |

### 4.2 交互 / UI 维度

| 项 | 主流做法 | Personal Life OS | 差距 |
|---|---|---|---|
| 记账路径 | 悬浮按钮 / 小组件 / 首屏直达，3 秒内完成 | 需导航到记账页填表 | **高** |
| 连续记账激励 | 连续天数、勋章、角色互动 | 仅打卡有，记账无 | 中 |
| 空状态引导 | 新手引导、示例数据 | 有 `seed_demo`，但无 UI 引导 | 中 |
| 批量操作 | 批量编辑/删除/改分类 | 无 | 中 |
| 主题个性化 | 40+ 主题（滴答清单） | 有主题切换 | 已具备 |
| 移动端体验 | 原生级 | PWA + 底部导航 | 已具备 |
| 动效与微交互 | Things 3 级别 | 基础 | 中 |

### 4.3 数据维度（我们的优势）

| 项 | 主流产品 | Personal Life OS |
|---|---|---|
| 数据所有权 | 存平台服务器，导出受限 | ✅ **完全自有**（自托管） |
| 隐私 | 依赖平台政策，需上传云端 | ✅ **不上传第三方** |
| 平台停运风险 | 有（Mint 2024 已关停） | ✅ 无 |
| 备份 | 平台负责 | ✅ `backup_db` 命令 |
| 多端同步 | 云端自动（开箱即用） | ⚠️ 需自行部署 |
| 上手门槛 | 下载即用 | ⚠️ 需部署（对个人项目可接受） |

**结论**：数据主权是我们的**核心差异化优势**，但"数据导出"缺位会削弱这个优势——用户拿不走的数据，不算真正自有。

## 5. 改进建议（按投入产出比排序）

### P0 — 建议优先做（成本低、收益高、全行业标配）

| # | 改进项 | 理由 | 预估成本 |
|---|---|---|---|
| 1 | **全局搜索** | 全行业唯一"人人都有我们没有"的能力；数据越多越刚需 | 低（Django Q 对象 + 一个页面） |
| 2 | **数据导出（CSV）** | 补齐"数据自有"闭环；也是开源项目的基本诚意 | 低（`csv` 模块 + view） |
| 3 | **快速记账入口** | 首页悬浮按钮 + 快捷输入，把记账压到 3 秒内。这直接决定"能不能坚持" | 中（前端为主） |

### P1 — 结构性能力（补齐后产品上一个台阶）

| # | 改进项 | 理由 |
|---|---|---|
| 4 | **标签系统** | 比分类灵活一个量级，支持多维度检索（如"#旅行 #2026 #待报销"） |
| 5 | **账户 / 多账本** | 区分现金/银行卡/支付宝，支持转账与余额。这是记账软件的 Adult 阶段 |
| 6 | **日历视图** | 任务/提醒/支出按日历呈现，是滴答清单四合一的核心 |
| 7 | **数据导入（CSV）** | 与导出成对，决定用户能否从钱迹/随手记迁过来 |

### P2 — 体验增强

| # | 改进项 | 理由 |
|---|---|---|
| 8 | **图片识别记账** | 已有 AI 基础设施，可复用 AI provider |
| 9 | **游戏化激励** | 连续记账天数、月度成就徽章（对标叨叨/松鼠） |
| 10 | **批量操作** | 列表页批量删除/改分类 |
| 11 | **全局快捷键** | 如 `N` 新建、`S` 搜索、`/` 聚焦输入 |
| 12 | **四象限视图** | 任务按"重要×紧急"矩阵呈现 |

### 不建议做

| 项 | 原因 |
|---|---|
| 银行自动同步 | 自托管难、需对接 Plaid 类服务、合规风险高、与"数据自有"理念冲突 |
| 投资 / 持仓追踪 | 复杂、需实时行情源、非本项目核心 |
| 多人协同 | 数据模型与权限体系改动大，与个人项目定位不符 |

## 6. 值得借鉴的产品洞察

1. **"记不记得"不是问题，"能不能坚持"才是**（叨叨/松鼠/Todoist Karma）
   游戏化不是花哨，而是把记账从"任务"变成"习惯"。

2. **flomo 的"每日回顾"是最低成本的复盘机制**
   不需要用户主动写复盘，系统把旧笔记推给你。我们有 Review 模型，可以做成"每日随机推送 1 条旧笔记"。

3. **YNAB 证明了：方法论比功能更值钱**
   同样是预算功能，YNAB 用"四法则"包装后，用户愿意付 $109/年。我们的预算/异常检测如果能包装成一套明确的方法论（比如"三步管钱法"），说服力会强很多。

4. **钱迹靠"导入能力"差异化**
   迁移成本是用户换软件的最大障碍。做好导入，等于降低了别人用我们的门槛。

5. **随手记的反面教训：功能多 ≠ 好用**
   它功能全市场最全，却被吐槽"普通人用不上这么多"。我们应保持"一体化但克制"。

6. **MoneyWiz 的"现金流预测"是最被称道的能力**
   点日历任意日期 → 看到未来余额。我们有固定支出（RecurringExpense）数据，做这个预测的基础已经有了。
