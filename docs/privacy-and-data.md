# Personal Life OS — 隐私与数据权利

## 数据所有权

你的数据**完全属于你**。所有数据存储在你自己控制的服务器上，不经过任何第三方。

## AI 隐私

| 原则 | 实现 |
|------|------|
| 本地优先 | 简单输入使用规则解析，不调用 AI |
| 敏感检测 | 身份证号、银行卡号、密码、验证码 → 自动跳过 AI |
| 用户控制 | 可随时关闭 AI（`ai_parsing_enabled`） |
| 日上限 | 单日调用次数可设上限 |
| 透明 | AI 调用记录可查询（`ConversationLog`） |
| 无密钥泄露 | API Key 仅存 `.env`，代码和日志中不出现 |

## 数据存储

| 数据 | 存储位置 | 加密 |
|------|----------|------|
| 消费记录 | 本地 SQLite/MySQL | 数据库文件可磁盘加密 |
| 任务/提醒 | 本地 SQLite/MySQL | 同上 |
| 账户密码 | Django PBKDF2 哈希 | 不存储明文 |
| API Key | `.env` 文件 | 文件权限控制 |
| 备份 | `backups/` 目录 | 可选 AES-256-GCM 加密 |

## 数据权利

| 权利 | 实现 |
|------|------|
| 导出 | `/accounts/export/` — JSON 全量 / CSV 简表 |
| 删除 | `/accounts/delete-account/` — 输入 DELETE 二次确认 |
| 修改 | 所有记录 CRUD 可编辑 |
| 软删除 | 支出/任务/笔记 `is_deleted` + `deleted_at` 可追溯 |

## 日志与审计

| 日志 | 不记录什么 |
|------|-----------|
| AuditLog | 不记录密码、API Key、完整敏感信息 |
| 应用日志 | 不记录请求体中的敏感字段 |
| 邮件通知 | 不发送金额、分类细节 |
| Git 历史 | 0 次密钥泄露（已审计确认） |
