# Personal Life OS — V0.2 需求文档

## 版本目标

从单用户原型升级为**安全、可长期维护**的个人生活管理系统基础。

## 背景

V0.1 实现了核心流程验证：语音输入 → 规则解析 → 用户确认 → 保存 → 今日看板。但系统存在以下根本性问题：

1. **无用户系统**：所有数据全局共享，无法区分个人数据
2. **单表混用**：Entry 表承载支出/待办/随心记，字段大量可空
3. **无工程基础**：缺少 CI/CD、文档体系、测试覆盖
4. **安全缺失**：无登录保护、无数据隔离

## 功能列表

### F1：建立文档体系（V0.2-01）
- docs/architecture.md / data-model.md / v0.2-requirements.md / v0.2-acceptance.md

### F2：用户注册与登录（V0.2-02~03）
- 注册页、登录页、登出；未登录跳转登录页；Bootstrap 样式

### F3：用户扩展模型（V0.2-04）
- UserProfile（OneToOne → User）：时区/货币/预算/AI开关

### F4：数据模型拆分（V0.2-07）
- Expense / Task / Note / Category 四张新表，Entry 保留

### F5：用户数据隔离（V0.2-06）
- 所有查询通过 request.user 过滤；禁止 objects.all()

### F6：基础 CRUD（V0.2-08）
- 列表/详情/编辑/软删除；权限守卫；Bootstrap 页面

### F7：测试与 CI（V0.2-02/10）
- 79 个测试；GitHub Actions push/PR 自动运行

### F8：审计日志（V0.2-09）
- AuditLog 记录修改/删除/登录失败；不存密码

## 约束条件

1. 所有业务数据绑定当前登录用户
2. 金额必须 Decimal，禁止 float
3. AI 只生成草稿，用户确认后才写库
4. 不得提交 .env、密钥、数据库文件
5. 保持 Django 单体架构
