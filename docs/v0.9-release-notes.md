## 版本目标

V0.9 是**功能完整度与体验**的双重跃迁：

1. 补齐主流记账 App 的核心能力（游戏化激励、批量操作、四象限、OCR、语音记账、记账提醒、报表同比环比、储蓄目标、信封预算、净值趋势、现金流预测、全局快捷键）；
2. 以 **taste-skill 重设计**统一全站视觉语言（指挥中心首页、主题色图标瓦片、统一 1.5px 图标库、品牌 Hero 令牌化），再经 **impeccable 审计与打磨**达到生产级质量；
3. **差距清单落地阶段**补齐与头部产品的差距——P0 级（周期性账单自动入账、支付宝/微信 CSV 导入、凭证附件、回收站/撤销）与 P1 级（年度账单、规则自动分类、N+1 查询消除、多币种、移动端滑动手势），全部本地提交并通过完整测试套件。

## 功能摘要（V0.9 核心）

### V0.9-01 游戏化激励（gamification）
- `Badge` 模型（user/key/earned_at，唯一约束）；9 枚徽章（首笔 / 30 笔 / 100 笔 / 连续 3·7·30 天 / 月满勤 / 8 分类 / 3 标签）
- 连续打卡按本地日期计算（避开 SQLite UTC 截断导致跨零点 streak 错）；徽章达成即永久点亮
- 成就页 `/gamification/` + 首页「记账打卡」紧凑卡 + 侧边栏入口

### V0.9-02 批量操作（batch）
- `batch_expense_action`：删除（软删）/ 加标签 / 设账户 / 清账户
- 越权隔离：按 `user` + `is_deleted` 过滤；转账类型排除账户操作避免脏数据
- 账目列表行内复选 + 底部浮动批量条（全选本页 / 加标签 / 设账户 / 删除）

### V0.9-03 四象限任务视图（quadrant）
- `Task` 加 `important` / `urgent` 布尔；`/tasks/quadrant/` 按 **重要 × 紧急** 分 4 格
- `task_toggle_flag` 即时翻转「重 / 急」小标记；编辑页复选框回显；侧边栏入口

### V0.9-04 图片识别记账（OCR）
- 可插拔 `OCRProvider`：`TesseractOCRProvider`（本地）/ `CloudOCRProvider`（外部服务）/ `MockOCRProvider`（测试）
- 上传 → 识别 → 启发式提取金额 / 日期 / 商户 → 确认页预填 → 保存；侧边栏「图片记账」入口
- ⚠️ 环境：本机需 Tesseract 二进制或配置云 endpoint 方可**实际**识别（测试用 Mock 全链路通过）

### V0.9-05 全局快捷键
- `N` 快速记账 / `S` 搜索 / `?` 帮助弹窗（输入框内不触发，Esc 关闭）
- 帮助弹窗 + `.lf-kbd` 样式

### V0.9-06 现金流预测
- `forecast.py`：账户余额 − 未来固定支出，按 weekly / monthly / quarterly / yearly 发生日生成，破零检测
- `/forecast/` 页（Chart.js 折线 + 即将扣款列表）+ 首页现金流卡片 + 侧边栏入口

### V0.9-07 语音记账
- `/api/voice-expense/` 接入 Web Speech API（zh-CN），不支持时静默隐藏入口
- 复用 `parser.parse_text` 即时入账，`source="voice"`

### V0.9-08 记账提醒
- `UserProfile.daily_log_reminder_enabled` + `daily_log_reminder_time`；复用 Reminder 引擎生成每日提醒
- 首页未记账时显示 nudge 并联动快速记账；Profile 开关 + 时间选择

### V0.9-09 报表增强
- `/reports/`：预设（本月 / 上月 / 今年 / 去年 / 全部）+ 自定义时间区间
- 本期收入 / 支出 / 结余 + **环比 / 同比**增幅 + 结余率；分类支出 / 收入构成；每日趋势 Chart.js
- 打印 / **导出 PDF**（`@media print`）；侧边栏入口

### V0.9-10 储蓄目标
- `SavingsGoal` 模型（目标额 / 当前额 / 图标 / 截止日）；进度、需月攒、增删改、存入 / 取出（金额不为负）
- 首页储蓄摘要卡；侧边栏入口

### V0.9-11 信封预算
- `envelopes` 视图：按月聚合每信封 预算 / 已用 / 剩余 / 进度 / 超支；**花销节奏**（偏快 / 正常 / 偏慢）+ 月末超支预测
- 支持调整已有信封 / 新增信封；汇总 已分配 / 已用 / 未分配 / 总进度

### V0.9-12 净值趋势图
- `BalanceSnapshot` 模型（按日快照）；`daily_balance_series` 高效逐日序列（O(流水+天数)）
- `/net_worth/` 页：Chart.js 折线 + 区间切换（30 / 90 / 180 / 365 / all）+ 账户构成**环形图** + 回填命令 `snapshot_balances`
- 首页净值概览卡（迷你走势，涨红跌绿中国习惯）

### V0.9-13 整体 UI 重设计（taste-skill + impeccable）
- **①A 首页双栏「指挥中心」网格**（≥1024px 两列 `1.65fr / 1fr`，Hero 跨整宽，侧栏 sticky）
- **③A 装饰 emoji → 主题色图标瓦片**（保留用户数据 emoji）；全站区块头统一加图标瓦片
- **⑤B 全站图标库统一 1.5px 描边**（193 图标 + Hero 进度环 6/8 按比例保留）
- **②A 品牌 Hero 渐变令牌化**（`.lf-hero--brand`），仅用于 Hero + 核心 KPI
- impeccable 审计修复：**P1** 尊重 `prefers-reduced-motion`（关闭 Chart.js 动画）；**P3** Hero 令牌化去除内联硬编码渐变
- impeccable polish：36 个装饰性图标加 `aria-hidden`；象限瓦片尺寸对齐标准 38px
- 维持系统字体栈（**④A**）、6 主题、暗色、焦点环、涨红跌绿中国习惯

## 差距清单落地（P0 / P1 补齐）

> 与头部记账 App 对比后识别的能力差距，按优先级 P0（发布阻塞）/ P1（体验关键）落地。全部本地提交并通过完整测试。

### V0.9-14 周期性账单自动入账（P0-1）
- `RecurringBill` 模型（金额 / 分类 / 账户 / 周期 day·week·month·quarter·year + 下次执行日 `next_run`）
- 管理命令 `post_recurring_bills`：按 `next_run` 批量入账并推进下一周期；可手动触发或接入定时任务
- 列表/首页显示「待执行」提示；越权隔离按 `user` 过滤
- 测试：`tests_recurring.py` 29 项

### V0.9-15 支付宝 / 微信 CSV 导入（P0-2）
- `import` 视图：上传 CSV → 解析 → 列映射（商户 / 金额 / 日期 / 收·支 / 分类）→ 批量确认入账
- 适配支付宝 / 微信导出列结构（摘要 / 交易时间 / 金额 / 收·支方向）
- 重复检测（按 来源 + 外部 ID / 哈希）避免重复导入；越权隔离
- 测试：`tests_import.py` 30 项

### V0.9-16 凭证附件（P0-3）
- `Expense` 关联附件（`FileField` / `media/`）；上传 / 预览 / 删除
- 列表与详情显示附件缩略；软删随账目隔离
- 权限按 `user` 过滤；删除同步清理物理文件
- 测试：`tests_attachment.py` 24 项

### V0.9-17 回收站 / 撤销（P0-4）
- 全站统一软删 `is_deleted`；回收站视图列出可恢复条目
- 支持 **恢复** / **彻底删除**（彻底删除含附件物理清理）
- 列表「撤销删除」即时恢复，降低误删损失
- 测试：`tests_trash.py` 21 项

### V0.9-18 年度账单（P1-7）
- `/annual/` 年度汇总：收入 / 支出 / 结余、月度走势、分类 Top、同比
- 打印 / 导出 PDF；侧边栏入口
- 测试：`tests_annual.py` 7 项

### V0.9-19 规则自动分类（P1-8）
- `CategoryRule` 模型（关键字 / 正则 / 目标分类 / 优先级）

- 规则管理页（增删改 / 优先级排序）
- 测试：`tests_category_rules.py` 26 项

### V0.9-20 N+1 查询消除（P1-9）
- 系统排查 13 个列表视图，定位 3 处真实 N+1：
  - `note_list` 循环访问 `n.user` → `select_related("user")`
  - `dashboard` 大额定项调用 `display_title` → `e.category` → `select_related("category")`
  - `account_list` 逐账户 `a.balance` 触发 4 次聚合 → 改为 2 条 `GROUP BY` 聚合
- 用 `CaptureQueriesContext` + `assertNumQueries` 锁定回归（查询数不随行数增长）
- 测试：`tests_nplus1.py` 5 项

### V0.9-21 多币种记账（P1-5）

- `Account` 新增 `currency`；`currency.py` 提供 13 种币种元数据与 `format_money`/`to_base` 工具
- **向后兼容**：`amount` 仍为统计口径，657 项既有测试零回归
- 测试：`tests_currency.py` 11 项

### V0.9-22 移动端滑动手势（P1-6）
- 可复用 `.lf-swipe` 组件（Pointer Events，触屏 + 鼠标通用）
- 账目列表左滑揭示「编辑 / 删除」操作；保留垂直滚动；阈值揭示 + 过拖阻尼
- 纯前端增强，任务 / 笔记列表可后续复用，无新增测试

## 已知限制

| 类别 | 限制 | 计划 |
|------|------|------|
| OCR | 本机无 Tesseract / 未装 pytesseract，实际识别需装二进制或配云服务 | 按需启用 |
| 语音 | 依赖浏览器 Web Speech API（Chrome / Edge），不支持时无入口 | 渐进增强 |
| 多币种 | ✅ 已落地增量 MVP（CNY 锚定 + 手动汇率）；暂未接外部汇率 API，统计口径仍为单币种 `amount` | 后续按需接入实时汇率 |
| 银行同步 / 投资 / 多人协同 | 不计划 | 与自托管 / 数据自有定位冲突 |
| CSP 头 | 未配置 | 生产部署审查 |
| 推送通知 | Web Push 需 HTTPS + VAPID | 生产部署时配置 |

## 部署提示

- 经 `Dockerfile`（gunicorn -w1）由 **Railway 自动部署**；推送 `release-v0.9.0` 即触发
- 必须环境变量：`DJANGO_DEBUG=false`、`DJANGO_ALLOWED_HOSTS`（具体域名，禁 `*`）、`DJANGO_ENVIRONMENT=production`
- `collectstatic` 已接 whitenoise；注意 Dockerfile 中 `... || true` 会**静默吞掉收集失败**——上线前确认构建期能成功 `collectstatic`，否则上线后 CSS/JS 全 404
