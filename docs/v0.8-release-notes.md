# Personal Life OS — V0.8 发布说明

> 发布日期：2026-08-11 | 标签：`v0.8.0` | 提交：`9d4ba9e`

---

## 版本目标

V0.8 聚焦于**安全加固、生产部署准备和用户数据权利**，使项目从开发原型升级为可在生产环境稳定运行的个人应用。

---

## 功能摘要

### V0.8-01 威胁模型
- `docs/threat-model.md`：9 个威胁场景
- 每项含威胁描述、当前防护、残余风险、建议
- 风险矩阵（可能性×影响）

### V0.8-02 生产环境配置
- `DJANGO_ENVIRONMENT` 环境感知
- 生产模式自动启用：HTTPS 重定向、HSTS、安全 Cookie
- 密码校验器（≥8 位、常见密码、数字）
- 日志轮转：`logs/app.log`(10MB×5) + `logs/error.log`(10MB×3)

### V0.8-03 登录与会话保护
- `LoginRateLimitMiddleware`：同 IP 5 次失败 → 锁定 15 分钟
- Session 超时 2 小时 + 关闭浏览器即退出
- 密码重置完整流程（4 页）
- Admin 保护（生产模式 `DEBUG=False`）

### V0.8-04 MySQL 正式迁移
- `docs/mysql-migration.md`：完整迁移指南
- `verify_db` 命令：Decimal/DateTime/索引/软删除/字符集
- 最小权限账号（7 项权限）+ 回滚方案

### V0.8-05 备份与恢复
- `backup_db` 命令：JSON→gzip→可选 AES 加密
- `restore_db` 命令：`--latest`/`--dry-run` + YES 确认
- 保留策略：最近 7 天 + 4 周

### V0.8-06 数据权利
- `/accounts/export/`：JSON（全量）/ CSV（简表）
- `/accounts/delete-account/`：输入 DELETE 二次确认
- 软删除：`is_active=False` + email 匿名化 + 审计

### V0.8-07 部署与监控
- `deploy/`：Gunicorn + Nginx + systemd 配置
- `/health/`：健康检查端点（无需认证）
- `docs/deployment.md`：完整部署流程 + cron 定时任务

## 已知限制

| 类别 | 限制 | 计划 |
|------|------|------|
| 安全 | 无 2FA | 后续评估 |
| 安全 | CSP 头未配置 | V0.9 审查 |
| 性能 | 无 Redis 缓存 | 个人使用够用 |
| 备份 | 无异地备份 | 手动操作 |
| 通知 | Web Push 需 HTTPS + VAPID | 生产部署时配置 |
| 图标 | PWA 图标为动态生成 | 可替换为真实图标 |
| 邮件 | 依赖 SMTP 配置 | 生产环境配置 |
