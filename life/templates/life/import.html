把其他记账软件的数据导进来。先上传预览，确认无误后才写入，不会一上来就改你的数据。

① 支持这三种文件

  • 支付宝账单 — 支付宝 App：我的 → 账单 → 右上角「…」→ 开具交易流水证明 → 用于个人对账 → 发到邮箱
  • 微信支付账单 — 微信：我 → 服务 → 钱包 → 账单 → 右上角「常见问题」→ 下载账单 → 用于个人对账 → 发到邮箱
  • LifeOS 导出 — 本应用导出的 CSV，表头为 {{ expected_header|join:"、" }}

邮箱收到的是加密压缩包，解压出里面的 .csv 再上传。
两家导出的文件都是 GBK 编码、且带十几行前置说明——这些会自动识别，直接传原文件就行，不用手工整理。

更多关于过滤规则与自家 CSV 格式…
· 自动过滤：交易关闭、已退款、支付失败的单据不计入账目
· 不计收支：余额宝转入、零钱提现这类内部划转不算消费，会跳过
· 分类：按账单自带的「交易分类 / 交易类型」归类，找不到会为你新建
· 去重：按订单号精确判重，同一份账单导入两次也不会翻倍
· 自家 CSV 的日期支持 2026-08-29 或 2026-08-29 14:30；类型填 支出 / 收入 / 转账；金额为纯数字；状态与来源两列可留空
